## 已接入：UCI Online Retail

- 原始来源：[UCI 官方数据页](https://archive.ics.uci.edu/dataset/352/online%2Bretail)。引用：Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. [DOI:10.24432/C5BW33](https://doi.org/10.24432/C5BW33)。
- 许可：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，[完整条款](https://creativecommons.org/licenses/by/4.0/legalcode)。分享数据或加工结果时保留来源、作者、许可链接并说明修改；不暗示原作者认可本项目。
- 英国零售商的历史交易明细，时间范围为 2010-12-01 至 2011-12-09，541,909 行。字段为单号、条目编码、描述、数量、记录时间、单价、客户编码、国家／地区；货币为英镑。C 开头单号代表取消。
- 首次接入选择它的理由：官方免登录下载、字段含义较明确、许可允许在署名条件下复用、真实数据含质量问题。它用于验证系统的数据处理，不证明当代国内电商经营规律。
- 本地数据在忽略目录 `data/raw/uci-online-retail/`，不打包进 Git 仓库。下载脚本校验固定 ZIP 和 XLSX 哈希，源文件更新时要求重新审查，不能悄悄替换基线。
- ZIP SHA-256：`f5385cbb54bbebf7196389109c6b0621faab0c304e3702548165e71c84aede8b`。
- XLSX SHA-256：`43465a06f2ccf7c8b5bd2892bc7defb52f97487934fe93b16ae4c3936424676d`。

**本项目的加工方式**：按确认的映射解析原始记录，隔离不符合当前数量／单价规则的行；保留并标记完全重复源行；只发布汇总值、异常数量和少量源行编号。没有将客户编码或逐笔明细放进报告。汇总结果仍注明源数据及加工条件。

**不能从该文件推导**：支付到账、退款现金流、取消与原订单的可靠关联、商品级退款率、成本利润、广告 ROI、时区转换和严格因果解释。包含邮费等条目的可能性需要保留，当前金额称“记录金额”，不是商品 GMV。缺客户编码不等于该销售不存在。

官方元数据页面的 “Has Missing Values? No” 与实际读取不一致：文件中客户编码缺失 135,080 行，描述缺失 1,454 行。项目采用实际文件检查结果，原始证据见 [完整报告](probes/uci-invoice-2026-11-05.json)。公开数据页也不能代替数据校验。

## 合成数据

`examples/data/` 中两份 CSV 均为本项目人工设计的合成样例，不含真实客户数据。两者表达同一业务事实，但列名、状态表示与金额单位不同。中文列名不表示它来自国内电商平台。

它们用于检查金额、粒度、能力限制与映射，不用于报告真实用户收益或 Agent 准确率。
