# 阶段 2b：受控 LangGraph 单 Agent 基线

日期：2026-11-06。工程接入和固定小样本真实模型初验收完成；完整产品阶段 2 / 稳定性阶段 3 仍未整体完成。

## 与阶段 2a 对比

| 维度 | 阶段 2a | 阶段 2b |
| --- | --- | --- |
| 用户输入 | 明确 metric/start/end/as_of | 兼容旧格式，新增自然语言 question 任务 |
| 执行 | Python 直接调用确定性工具 | 一个模型自主选工具，查看结果并可修正参数；由 create_agent 生成 LangGraph 运行图 |
| 数值可信度 | 工具生成金额与 SQL 证据 | 保留工具真值，模型只选证据；报告金额、差值和文字模板由代码生成 |
| 数据不足 | 工具错误并结束任务 | 可形成明确的 needs_clarification / unsupported 报告 |
| 图状态 | 没有图执行状态 | 本地 SQLite checkpoint，绑定任务/输入/问题/提示词/实现/版本；同逻辑任务可恢复 |
| 业务发布 | Java 租约、事务与幂等 | 继续由 Java 决定；另检查 Agent 报告绑定与比较值 |
| 调用与费用限制 | 确定性工具超时与尝试上限 | 增加最多 5 次模型尝试、4 次业务工具调用；独立费用预留，跨恢复不重置 |
| 工程验收 | 18 项任务闭环，46 项数据测试 | 42 项（包含原 18 项闭环）全部通过；原数据 46 项另测通过 |
| 真实模型验证 | 0 次模型调用 | 35 次个人 DeepSeek 请求，开发 3/3，保留两轮各 6/7，12/14 = 85.7% |
| 数值重算 | 样例指标可核查 | 17 份真实报告独立重算，数字/引用错误 0 |
| 已知问题 | 尚无自然语言任务能力 | 利润问题两轮都拒绝，但拒答原因分类与预设不一致；保留失败，不改分数 |
| 成本证据 | 没有模型费用 | 保守费用上界 0.137988 元，授权总预算 5 元；未查询实际账单 |

## 后续优先事项

1. 解决“缺数据”和“当前能力不支持”的用户指引边界；加入新开发样本与独立保留问题族，不继续把已看过的保留题当盲测。
2. 增加外部数据版本/映射与简单界面，让用户能够提交问题、看到状态、补充条件并核查证据。
3. 部署前重新选择并实测生产数据库/checkpointer、身份认证、预算生命周期、迁移与进程管理。
4. 扩大单 Agent 真实评测及试用，再讨论专家 Agent；未进行多 Agent 对照，不声称多 Agent 优势。

当前简历可写已验证的跨语言任务闭环、单 Agent 工具接入、证据校验、故障恢复和小样本评测，不可写生产高可用、真实商家效率提升或泛化准确率 85.7%。
