## 本阶段实现

- 多阶段 Dockerfile，项目构建上下文白名单、哈希锁定 Python 依赖、官方固定 Maven archive 校验；应用非 root、只读根、独立持久卷、CPU 之外的内存/PID/日志限额、健康检查。
- Compose 拆业务应用、PostgreSQL 和可选 Caddy；应用/数据库不映射宿主端口，默认应用网络不出站；数据库密码采用 configtree file secret，容器不接收模型 Key。
- Java/Python 共用启动器和项目持久状态锁，console 日志交由容器轮转；受限数据库账户、备份/恢复路线沿用已验证实现。
- 固定 Actions commit、只读源码权限、实际镜像 digest 留存、离线契约＋全新 Compose TLS/任务/重启验收脚本。尚未运行，镜像解析曾在本机超时。
- 更新 README、MIT/第三方声明、49 项 Python 与 52 项 Java 的实际依赖许可清单、面试四点与前后对照。没有把工程测试写成模型成功率。
- 创建并从浏览器核对个人公开空仓库，准备受限定的固定提交发布入口；源码上传需个人终端认证，详见账户边界。
