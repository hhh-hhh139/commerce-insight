# 阶段 5e：备份维护入口的路径边界修复

日期：2026-11-08。此项是首次发布候选 `0e48851` 后的独立修复，不改变用户正在执行的固定提交发布任务。

## 问题与复现

检查部署手册中的备份入口时，实际复现了两个遗漏：[修复前记录](../probes/backup-path-before-2026-11-08.json)。`Path.absolute()` 保留 `..`，原 `is_relative_to(.local)` 检查因此接受了最终落在 `.local` 外的路径；恢复时直接读取 `manifest.json`，符号链接清单先被读取再被拒绝。范围是本地维护 CLI，不是网页上传接口。复现没有创建越界目标，所有测试文件都位于本项目临时目录。

备份方案仍沿用此前的 Metabase/原生 PostgreSQL 调研；该修复的两种路径处理方案、官方依据与选择见[部署研究补记](../research/016-deployment-and-database.md)。选择在任何文件检查前拒绝 `..`，并让清单在首次读取前经过已有的符号链接检查；不更换备份格式或数据库协议。使用者须提供不含 `..` 的直接路径。

修复前源码归档：365 文件，`before-backup-path-fix-20261108/source.tar.gz`，SHA-256 `ae0755e9ed585d8b7215583aab13001dcd64ad75273e63371d6ee332ffdc2644`。成员和逐文件 SHA 已核验。

## 实施与效果

`scripts/backup_state.py` 统一入口拒绝父目录跳转；读取 manifest 前检查其自身路径。新增独立反例测试，接入后续干净 Linux CI 的离线检查。

- [路径边界 3/3](../probes/backup-path-after-2026-11-08.json)：在文件检查前拒绝父路径跳转；backup/restore 的全部路径参数在数据库访问前被拒绝；符号链接清单在内容读取和目标创建前被拒绝。
- [真实备份回归 5/5](../probes/backup-path-regression-2026-11-08.json)：总计 16.738 秒（unittest 15.043 秒），包含外部合成数据版本、历史/排队任务、checkpoint 续跑、预算与登录状态连续性、受限角色、状态锁与启动器/configtree。原预算字节未改变，无模型请求。

这证明本次路径反例被关闭且既有恢复流程未回归，不扩大到 Linux/容器部署、备份来源真实性或同一 OS 用户并发替换目录的防御承诺。个人认证、真实 CI、最新模型评测仍分别待完成。

复现：

```sh
.local/agent-venv/bin/python -m unittest discover -s tests -p test_backup_paths.py -v
.local/agent-venv/bin/python experiments/postgres/verify_backup.py .local/backup-path-regression.json
```

面试说明：备份恢复除了验证数据能恢复，也要验证失败发生在副作用之前。通过最小反例发现词法路径判断遗漏，比较规范化与提前拒绝，选择符合“只在项目目录、禁止符号链接”约束的局部修复，再用真实 PostgreSQL 和图状态恢复证明主流程不受影响。
