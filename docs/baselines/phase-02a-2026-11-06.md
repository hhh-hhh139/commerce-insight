## 实测摘要

- Java 首次 Maven 构建成功；没有 JUnit 用例，跨语言验收才是本阶段测试入口。
- 初轮 17/17 通过，补强后最终 18/18 通过；测试共 22.108 秒（本机套件耗时，不是性能承诺）。原有数据回归 46/46 通过。
- 并发 8 路同 key 提交得到一个任务；并发 8 路领取得到一个有效租约；重传成功结果只有一条成功事件。
- Java SIGKILL 重启后排队、执行中、已完成状态保留；领取进程 SIGKILL 后重领有最多 3 次上限。
- 取消后子进程停止且晚结果不能复活任务；错误证据不能提交；新注册快照不改变旧任务输入。
- 一键演示实际启用独立 JVM 和 Python Worker，返回 23000 分和完整证据。原始示例记录见 [演示结果](../probes/task-loop-demo-2026-11-06.json)。
