## 前后变化与理由

此前仅分别验证标量、销售、退款，缺少完整复合问题对照。完整工具消息还会重复向模型发送 SQL 和溯源字段。研究 [014](../research/014-context-and-specialist-evaluation.md) 比较保持现状、框架 artifact 摘要、固定双专家；采用原生 `ToolMessage.artifact` 把完整证据留在 SQLite checkpoint，避免另写证据存储。现有 4 工具和有限口径暂不引入向量库。

现在增加两个内部研究选项，原公共入口不变。摘要内容保留查询、单位、指标版本、结果摘要和证据编号；发布仍从完整证据重建，并验证摘要、摘要对应 artifact 的哈希及快照/工作空间绑定。双专家各受 2 次模型/2 次工具限制，销售和退款能力在代码中分开；顺序执行，固定合并，不宣称动态协作或并行加速。一边缺参或拒答时不会把另一边结果当完整答案。

当前实际序列化样例完整/摘要字节：销售 4445 → 1561，退款 5028 → 1402（使用同一 JSON 紧凑序列化方式，见 [测量](../probes/context-measurement-2026-11-08.json)）。这是工具内容的字节数，不是整个请求 token、实测省费或质量指标。
