## 应用这些证据的边界

上述岗位支持重视工程、评测和业务交付的准备方向，但不证明本产品已有市场需求，也不要求照搬所有大厂组件。Java 是用户选择的能力补充，不是所有 Agent 岗位的统一门槛；LangGraph 是本项目已选工具，不是所有 JD 的唯一指定框架。

首版优先掌握数据结构、SQL、网络、Java 并发及事务等基础，并结合真实项目问题理解。训练、推理集群、复杂多 Agent 协议等只在目标岗位和问题明确后扩展。

面试材料逐模块积累：问题复现、比较过的方案、关键代码、失败轨迹、验证结果、局限和个人贡献。招聘方向变化时追加新日期的核验记录，不覆盖本次快照结论。
