# 退款专项评测

`cases.json` 在真实模型调用前固定：2 道开发题、6 道保留题（两轮）。人工核算基于项目合成账本，包含金额、部分退款笔数/订单数、支付来源、缺失商品归属、Top N 余项、零基数、空期、时区和拒答。不同问题族共用账本，不代表独立商家样本。

`verify.py` 验证评分器的 6 类行为：8 题脚本报告与人工期望一致、独立数据库重算、脚本不通过真实模型门槛、关键金额/归属篡改被检测、伪造文字/引用/时间被检测、零分母与验收门槛。没有模型 API 调用。

业务工程与运行命令见 [退款工具说明](../refund-change/README.md)。真实结果须记录运行数据、Prompt/实现/题集 SHA、逐题结果、重算审计、调用量、费用上界和时延。修改 Prompt 后原真实销售评测只代表历史版本；最终版本需要合并回归，不能直接沿用历史通过率。
